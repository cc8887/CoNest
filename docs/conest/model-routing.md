# 微信前台对话与后台工单

每位成员有自己的私有前台路由会话，保存微信对话上下文。新成员模式默认让前台使用 `hy4-flash`，并由全平台共用的一个 `hy4` worker 执行工单。管理员可在「评估 → 研判模型」和「执行 → 执行器模型」配置两个角色。[模型设置](../../src/policy.ts#L83) · [路由模型](../../src/app/role-models.ts#L34) · [新成员默认值](../../src/app/weixin-setup.ts#L47)

前台直接回答问候、闲聊和可当场回答的简单问题，不创建工单。成员明确委托工作或要求交付成果时，前台接单并派发独立工单。worker 忙碌期间，成员仍可在原微信私聊里继续对话，工单结果也回到原账号。[分流提示](../../prompts/private-router.md) · [直接回复](../../src/app/tools/main.ts#L223) · [原对话回传](../../src/core/replies.ts#L64)

开发机以真实腾讯流式模型和模拟微信传输验证了三轮连续陪聊。验证挂起后台 `hy4` 请求，直到三条聊天回复均已送达后再放行 worker，最后工单完成并回传。手机实收仍待重新扫码验收。

个人网页继续提供任务列表和工单操作。
