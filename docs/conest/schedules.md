# 成员定时任务

在已绑定的微信私聊或 CoNest 个人空间的「新任务」输入框直接提出请求，例如：**「从明天开始，每天北京时间 09:00（UTC+08:00）帮我生成一份当天的日程准备清单。」** 模型从本次明确请求调用专用工具，保存成功后才确认，不会先执行一张普通工单。请注明首次日期、时区和是否重复；首版支持一次、每天、每周，不支持自定义 cron、按月或仅工作日。重复按首个时间的固定 UTC 偏移计算，不自动跟随夏令时。

每位成员最多保留 20 个生效的计划。个人空间「定时任务」显示本人的计划和下次时间（浏览器本地时区），也可取消。微信私聊可问「我有哪些定时任务？」或请助手取消某项计划。取消只影响未来运行；已排队或执行中的工单请在任务记录里另外停止。微信结果通过原绑定私聊的发件箱投递；它仍依赖当前有效的微信回复上下文。已开通个人网页的成员也可在那里查看工单结果。

## 飞书群设置

1. 管理员打开高级控制台的飞书来源设置，配置可用的同一个飞书机器人，开启「成员身份模式」和「允许已绑定成员在指定群创建定时任务」，打开私聊并明确列出允许的群。对应来源配置是 `identityOnly: true`、`groupSchedules: true`、`directMessages: true` 和 `chats`；首次切换成员身份模式按设置提示重启。关闭 `groupSchedules` 时保留原来的只识别模式。
2. 成员登录个人空间，在「渠道连接 → 连接飞书」生成配对指令，通过同一个机器人私聊发送，再回同一网页确认。成员必须有启用的个人空间，不要求绑定微信。
3. 在允许的群里发新消息或回复话题时 **@ 机器人**，明确写出执行时间和内容。开启[智能寻址](architecture.md#智能寻址)的群也接受可识别为发给 Bot 的自然语言请求。只有已绑定成员的实时消息会进入其私有路由。保存后机器人在原消息所在话题发固定确认，到期工单和结果只在发起人的个人空间。群内不能查看或取消任何人的计划。

普通微信群未接入；飞书群也不是一个共享租户。群消息来源的配置、成员状态及配对在保存确认和到期时重新校验。到期时发现群入口授权已移除或成员已解绑、停用，就取消该计划，不转向其他群或账号。

## 到期与恢复

- 调度在现有 CoNest Runtime 内运行，计划和去重键保存在原 SQLite 状态目录。运行时停机、休眠或管理员暂停期间不会触发；恢复后同一计划漏掉多次只补一次，不回放全部积压。
- 到期指进入原工单队列，不保证马上开始执行。重复计划不会在上一张工单未结束时再生成工单。任何已生成的工单仍走原成员权限、worker 槽位及报告流程。
- 目前验收采用模拟微信和飞书传输及模型工具调用，覆盖计划保存、指定话题确认、跨租户拒绝、重启、重复运行和撤销。尚未做真实飞书群、微信长时投递或 N100 常驻验收。
