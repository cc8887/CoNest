CoNest 微信前台陪聊与 Docker 预发布版，目标平台为 N100 的 `linux/amd64`。

- 每位微信成员拥有持续保留上下文的私有前台会话。问候、闲聊和简单问题直接回复，不创建工单。
- 明确委托交由独立工单 worker 执行。前台会话使用 `hy4-flash`，全平台共享一个 `hy4` worker。
- 同一成员在 worker 忙碌时可继续聊天，工单结果仍返回原微信账号。
- 保留 v0.2.0-alpha.1 的网页成员注册、扫码绑定、独立个人页面、共享工单队列和默认 CoNest 后台。
- Linux/amd64 构建执行完整检查。镜像 smoke 验证非 root、只读根文件系统/noexec 临时目录、后台认证、个人页面和重启。真实 DSH Runtime 的 mock 模型与微信验收覆盖 10 个租户、100 张工单及后台执行期间三轮陪聊。

镜像及其余部署附件见 SHA256SUMS。该 mock 微信传输不证明手机实收、N100 容量或多个真实微信账号已完成验收。升级说明见 DOCKER.md。
