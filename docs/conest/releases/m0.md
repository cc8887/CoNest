CoNest 的首个微信工单 Docker 验证版，目标平台为 N100 的 `linux/amd64`。

- 微信文本私聊已进入真实 SuperAgent Ticket、worker Report、Attention 和 outbox，开发机上的 hy4 工具调用及手机收件已确认。
- 主 Runtime 支持禁用 GitHub 后启动；默认只接受一个绑定 owner，使用单 worker。
- Docker 镜像附带 Node 24.22.3 和 DSH 0.2.1-alpha.2，宿主 Node 18 / pnpm 10 无需为容器升级。
- 附件包含可 `docker load` 的镜像归档、源码、Compose、模型环境模板与 SHA256SUMS。无内置密钥、微信凭证或私聊状态。

下载同版本附件，核对 SHA256SUMS 后按 DOCKER.md 部署：模型验证 → 私聊扫码 → init → 启动主 Runtime。扫码与管理端口只绑定宿主 127.0.0.1。PIN 与 API key 只在本机填写。

当前是单用户预发布版，家庭成员隔离、群聊、N100 容量、休眠与 Windows 开机恢复尚未验收。hy4 的初测响应存在数分钟延迟，后续仍需优化。不要把源码中的家庭授权纯函数当作运行时成员隔离。
